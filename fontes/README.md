# Referências Utilizadas

Este projeto foi desenvolvido com base em documentos públicos e oficiais relacionados à Lei Geral de Proteção de Dados (LGPD), à governança de dados e à segurança da informação.

## Fontes Oficiais

### Lei Geral de Proteção de Dados (Lei nº 13.709/2018)

Documento base utilizado para compreender os princípios, direitos dos titulares, bases legais e responsabilidades dos agentes de tratamento.

https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/l13709.htm

---

### Autoridade Nacional de Proteção de Dados (ANPD)

Portal oficial contendo guias, regulamentos, notícias e materiais técnicos.

https://www.gov.br/anpd/

---

### Guia Orientativo - Agentes de Tratamento e Encarregado (ANPD)

Documento utilizado para compreender as responsabilidades do Controlador, Operador e Encarregado (DPO).

https://www.gov.br/anpd/pt-br/centrais-de-conteudo/materiais-educativos-e-publicacoes/guia-orientativo-para-definicoes-dos-agentes-de-tratamento-de-dados-pessoais-e-do-encarregado#view

---

### Marco Civil da Internet

Marco regulatório brasileiro da Internet utilizado para contextualização jurídica.

https://www.planalto.gov.br/ccivil_03/_ato2011-2014/2014/lei/l12965.htm

---

### Controladoria-Geral da União (CGU)

Material utilizado para compreender governança e proteção de dados no setor público.

https://www.gov.br/cgu/pt-br/acesso-a-informacao/privacidade-e-protecao-de-dados/politica-de-privacidade-e-protecao-de-dados-pessoais-da-cgu

---

### Senado Federal

Material de apoio sobre proteção de dados pessoais.

https://www12.senado.leg.br/institucional/protecao-dados/plano-de-protecao

---

### Plano Estratégico da ANPD

Documento utilizado para compreender as diretrizes estratégicas da Autoridade Nacional de Proteção de Dados.

https://www12.senado.leg.br/transparencia/gestgov/sgidoc/arquivos/ppdp-2024-2026.pdf
